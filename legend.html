Legend Maker

Builds the instrument key for your videos — name, colour and shape per part. Draws straight onto a canvas, so Download PNG gives you a genuinely transparent file, and bare mode gives an OBS browser source that plays the intro once and fades out.

Instruments
NAME / SHAPECOL
Import reads a preset from the visualizer's presets/ folder and pulls in every routed part with its colour and shape. Presets don't carry the MIDI's track names, so parts arrive as "Track 3" unless you'd named them in the legend editor — rename them here.
Card
Colour box or dot when the shapes would only be noise. Note glyph is the shape of an individual note; path shape is the curve it travels along. Each instrument remembers both, so switching back and forth never loses a choice.
Intro animation
Output
Layouts save as their own JSON, separate from visualizer presets. Whatever you have here is also remembered in this browser automatically.
Video — Premiere
Downloads one .zip of numbered PNGs with real alpha. In Premiere: File → Import, select legend_0000.png, tick Image Sequence. Set the frame rate here to match your sequence, or fix it afterwards with right-click → Modify → Interpret Footage — Premiere otherwise assumes its own default and your timing drifts.
The checkerboard is preview only — it is never drawn into the PNG. Press B for bare mode (card only, nothing else), Space to replay the intro.
